## Week 1 - History
- One writing system can be used by many different languages.
- Cuneiform is an ancient writing system that used wedge-shaped marks on clay tablets.

## Week 2 - Bits and Bytes
- A bit is a binary digit with a value of 0 or 1. One byte contains 8 bits.
- RAM temporarily holds data while a computer is running, while persistent storage keeps data after the power is turned off.
- ASCII represents characters, such as letters and numbers, using numeric codes.

## Week 3 - Structure of Text
- Markdown and HTML are markup languages that add structure to text, such as headings and lists.
- JSON and XML are formats used to organize structured data.
- Escaping allows special characters to be treated as literal text instead of formatting or commands.

## Week 4 - Typing and Searching
- Touch-typing and keyboard shortcuts help people work with text more efficiently.
- Text editors, such as Notepad, vi, and VS Code, are used to create and edit plain text files.
- Regular expressions describe patterns that can be used to search for text.

## Week 5 - Command Line Interfaces
- A command line interface lets users interact with a computer by typing commands.
- A terminal provides the interface for entering commands, while a shell interprets and runs them.
- SSH provides a secure connection to a remote computer, while SFTP and SCP can transfer files securely.
